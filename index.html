Voxel Editor — Help

Click anywhere to close (or press F1).
WASD move  ·  Space/C up/down  ·  Shift sprint
Click the world to lock the pointer, then: LMB place  ·  RMB remove  ·  Middle click pick the block you're looking at  ·  Shift+LMB draw a line from the last placed voxel
Tab hold for the radial tool selector  ·  tap to cycle
Cube Delete tool: LMB a voxel for the first corner, LMB the opposite corner — every block and object in that cube goes in one undo step  ·  RMB cancels the pending corner
Paint tool: hold LMB and sweep to repaint block faces with the selected block's texture  ·  hold RMB to strip them back — one undo step per stroke
Spawn tool: LMB place / move the spawn  ·  RMB clear it  ·  R rotate the facing arrow (the arrow shows where the player looks)
1-9,0 hotbar slots  ·  B 0.5m/1m  ·  V slab variant (full / lower / upper half)  ·  R rotate selected object 90°  ·  E inventory — hover a block, press a number to put it in that hotbar slot
Ctrl+Z undo  ·  Ctrl+Shift+Z redo
F2 item editor — build a placeable object from colored micro voxels,
then place it from the inventory (E, "Placeable Objects" section)
F3 items editor — build an equippable item (e.g. a club): paint the shape,
G set the right-hand grip voxel (H the left-hand grip on 2-handed weapons), R aim the direction arrow, set damage/reach/cooldown
F4 NPC & quest editor — define characters and their questlines,
then drop them with the NPCs tool (Tab ring, G cycles the type)
LMB on a door opens its settings — lock it, or pick which way it swings (the plan arc drawn at each door shows the hinge and the swing)  ·  Shift+LMB builds there instead
F5 test run — walk at the spawn (C crouch, E open doors)  ·  F1 help  ·  Esc release pointer  ·  P polaroid filter (bloom + film grade)
F8 capture this view as a menu splash screen (save the world via Worlds first)  ·  Shift+F8 delete the nearest splash camera  ·  LMB on a camera gizmo picks its motion (orbit / static / zoom)

The sidebar on the left holds every action and the live inspector — ` hides / shows it
Ctrl+S save  ·  Ctrl+Alt+N new world (press twice to confirm)  ·  Ctrl+O load a file  ·  Ctrl+E export
F7 world catalogue — save, load and organize worlds for campaigns and splash screens  ·  I item catalogue  ·  F6 prefab library — a card puts the building in hand: LMB stamps it  ·  R turns it 90°  ·  F / Shift+F mirrors it across X / Z (for the flipped twin next door)  ·  RMB puts it away
Inside the prefab editor Shift+F6 (or Paste prefab…) opens the same library to stamp a finished prefab into the one being built
Save writes the map + objects straight to map/voxelbundle.json (no download) — run npm run server and open http://localhost:4173 so your world ships with the build
