Voxel Editor — Help

Click anywhere to close (or press F1).
WASD move  ·  Space/C up/down  ·  Shift sprint
Click the world to lock the pointer, then: LMB place  ·  RMB remove  ·  Middle click pick the block you're looking at  ·  Shift+LMB draw a line from the last placed voxel
Tab hold for the radial tool selector  ·  tap to cycle
Spawn tool: LMB place / move the spawn  ·  RMB clear it  ·  R rotate the facing arrow (the arrow shows where the player looks)
1-9,0 hotbar slots  ·  B 0.5m/1m  ·  V slab variant (full / lower / upper half)  ·  R rotate selected object 90°  ·  E inventory — hover a block, press a number to put it in that hotbar slot
Ctrl+Z undo  ·  Ctrl+Shift+Z redo
F2 item editor — build a placeable object from colored micro voxels,
then place it from the inventory (E, "Placeable Objects" section)
F3 items editor — build an equippable item (e.g. a club): paint the shape,
G set the right-hand grip voxel (H the left-hand grip on 2-handed weapons), R aim the direction arrow, set damage/reach/cooldown
F4 NPC & quest editor — define characters and their questlines,
then drop them with the NPCs tool (Tab ring, G cycles the type)
F5 test run — walk at the spawn (C crouch, E open doors)  ·  F1 help  ·  Ctrl+S save to browser  ·  Esc release pointer
F8 capture this view as a menu splash screen (save the world via Worlds first)  ·  Shift+F8 delete the nearest splash camera  ·  LMB on a camera gizmo picks its motion (orbit / static / zoom)
Worlds opens the world library — save, load and organize worlds for campaigns and splash screens
Save File writes the map + objects straight to map/voxelbundle.json (no download) — run npm run server and open http://localhost:4173 so your world ships with the build
