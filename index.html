Voxel Editor — Help

Click anywhere outside, or press F1 / Esc, to close.

Moving

WASD move · Space/C up/down · Shift sprint

Click the world to lock the pointer · Esc releases it

P polaroid filter (bloom + film grade)

Building

LMB place · RMB remove · Middle click pick the block you're looking at

Shift+LMB draw a line from the last placed voxel

B 0.5 m / 1 m grid · V slab variant (full / lower / upper) · R rotate the selected object 90°

Ctrl+Z undo · Ctrl+Shift+Z redo — or click the timeline in the sidebar

Tools

Tab hold for the radial tool ring · tap to cycle tools

Cube delete — LMB two opposite corners; everything inside goes in one undo step · RMB cancels

Paint — hold LMB and sweep to repaint faces · hold RMB to strip them back

Spawn — LMB place/move · RMB clear · R rotate the facing arrow

NPCs — drop characters made in the F4 editor · G cycles the type

Hotbar & inventory

1–9,0 hotbar slots

E inventory — hover a block, press a number to bind it to that slot

Editors

F2 object editor — sculpt a placeable object from micro voxels, then place it from the inventory

F3 equipment editor — paint the shape, G/H set the grips, R aim the direction arrow, set damage/reach/cooldown

F4 NPC & quest editor — define characters and their questlines

Doors, lights & wiring

LMB a door for its settings — lock it or pick the swing (the plan arc shows hinge and swing) · Shift+LMB builds there instead

Lights and switches open the same way; name a shared flag to wire a switch to its lights and doors

Test & capture

F5 test run — walk at the spawn (C crouch, E interact)

F8 capture the view as a menu splash screen (save the world via Worlds first) · Shift+F8 delete the nearest splash camera · LMB a camera gizmo to pick its motion

Files & libraries

Ctrl+S save · Ctrl+Alt+N new world (twice to confirm) · Ctrl+O load a file · Ctrl+E export

F7 world catalogue · I item catalogue · ` hide/show the sidebar

F6 prefab library — a card puts the building in hand: LMB stamps · R turns 90° · F/Shift+F mirrors · RMB puts it away. Inside the prefab editor Shift+F6 pastes another prefab in

Save writes straight to map/voxelbundle.json — run npm run server and open http://localhost:4173 so your world ships with the build
